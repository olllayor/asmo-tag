# Asmo identity

The working product name is **Asmo Tag**. The parent brand is **Asmo AI**. The Telegram bot's display name is Asmo. Its username is selected only after checking availability through BotFather. No username or domain is reserved by this document.

Asmo Tag describes the main interaction. A teammate tags Asmo, gives it work, and receives a result in the same conversation. Use the name consistently in configuration, help, task messages, and documentation. Do not imply an affiliation with Anthropic or call the product Claude for Telegram.

The more playful alternative is **Asmo Djinn**. It suggests a resident helper that a team summons when work needs doing. Keep this as a naming candidate rather than a second product. Asmo Relay is an alternative if customers respond better to a restrained infrastructure name.

Use plain product language. Say “Tag Asmo. Get the work done.” Explain an actual limitation when it affects a task. Use “simulated” prominently for offline providers and examples. Never make a fixture look like a live completed action.

Public searches on October 6, 2026 found no obvious competing AI product under the exact names Asmo Tag or Asmo Djinn. Search results are an incomplete conflict check. This is not trademark clearance, domain availability, or a verified Telegram username. Existing uses of ASMO alone mean the parent name cannot be described as globally unique.

The first visual proposals use black and white, dense rows, visible evidence, and exact action previews. The product's character comes from concise help and useful work. A fictional personality must never obscure permission decisions, uncertain effects, or who approved an action.
